🌐 Ulix Server

Ulix Server — это учебный проект, демонстрирующий реализацию легковесного TCP-сервера на C++ с собственным сетевым протоколом Ulix, разработанным с нуля. Проект включает в себя серверную часть на C++ и тестовый клиент на Python для проверки работоспособности. Протокол Ulix разработан как упрощенная альтернатива HTTP для образовательных целей, позволяя глубже понять работу сетевых приложений.

🚀 Особенности

- Собственный протокол Ulix — запросы и ответы построены на текстовых заголовках с разделителями | и /.
- Написан на чистом C++17 — без внешних зависимостей, используются только стандартные и системные библиотеки.
- Тестовый клиент на Python 3.9+ — для отладки и демонстрации работы протокола.
- Поддержка статики — сервер умеет отдавать HTML-файлы из папки www/.
- Встроенные команды — например, запрос /time возвращает текущее время сервера.
- Работа с файлами — поддержка методов GET и POST для чтения и сохранения файлов (с простой авторизацией через заголовок password).

Протокол Ulix (кратко)

Протокол Ulix является текстовым и состоит из двух строк.

Запрос:
method/get|datatype/html|code/ascii
/index.html

Строка 1 (Заголовки): метаданные запроса (метод, тип данных, кодировка, опциональные параметры).
Строка 2 (Тело): путь к файлу или команда.

Ответ:
ok|utf-8|html
<html><body><h1>Hello, Ulix!</h1></body></html>

Строка 1 (Заголовок): статус, кодировка и тип данных.
Строка 2 (Тело): запрошенный контент.

Сборка и запуск

Сервер (C++):
1. Открой решение ulix-server.sln в Visual Studio 2022 (или новее).
2. Убедись, что выбран стандарт C++17.
3. Собери проект (Ctrl+Shift+B) и запусти (Ctrl+F5).
4. Сервер запустится на порту 8080 (по умолчанию).

Клиент (Python):
Убедитесь, что используется Python 3.9+
python client.py

Пример запроса через Python:
import socket

request = "method/get|datatype/text|code/ascii\r\n/time\r\n"

with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as s:
    s.connect(('localhost', 8080))
    s.send(request.encode())
    response = s.recv(4096).decode()
    print(response)  # Вывод: ok|ascii|text\n2025-09-04 12:34:56
